# Guía de Estudio de Lengua - 4.º grado

Página web estática lista para subir a GitHub Pages.

## Archivos

- `index.html`: estructura y contenidos de la guía.
- `styles.css`: diseño visual y adaptación a celular/tablet.
- `script.js`: interacción de las respuestas en la práctica final.

## Cómo publicar en GitHub Pages

1. Crear un repositorio en GitHub.
2. Subir los archivos de esta carpeta.
3. Ir a `Settings > Pages`.
4. Elegir `Deploy from a branch`.
5. Seleccionar `main` y carpeta `/root`.
6. Guardar.

GitHub generará una URL pública para ver la guía.
